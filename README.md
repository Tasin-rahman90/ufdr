# Frontend Journey — U FDR 2505

A responsive, animated React photo story for the Creative IT Institute Frontend Development with React batch.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build, run:

```bash
npm run build
```

## Included

- Animated “Presented by Tasin Rahman” opening
- Course timeline, instructor tribute, class moments, and farewell gallery
- Sixteen student portrait cards, with the first eight named in the supplied photo order and the remaining cards labeled by number
- Exclusive, Evenza, and Cheffest project cards
- Click-to-enlarge photo viewer and responsive layouts

Photos and the Creative IT Institute logo are in `public/images`.
